# Проверка AmyxStats 1.0.0

Проверяются официальные PocketMine-MP 5.0.0 с PHP 8.1.34 ZTS и 5.44.3 с PHP 8.4.16 ZTS. Тесты, сборка и PHAR входят в исходники и релиз соответственно.

На каждой версии выполняются:

- 15 проверок хранения, атомарного отката, общих сумм и максимумов, вычисляемых коэффициентов, рангов и топов с несохранёнными изменениями, поиска по нику, ограничений входных данных, игровых дней, монотонного времени, повторного подключения и каждого из 531 объявленного плейсхолдера.
- 33 проверки на работающем сервере с производственным PHAR, включая командные алиасы, меню, доступ, события блоков, перемещение, PvP, смерти, мобов, предметы, крафт, AmyxAnvil и API ScoreHud.
- 1 проверка в отдельном процессе после полного перезапуска сервера: офлайн-профили, личные и общие счётчики, измерения по типам и топ.

Всего **98 сценариев** на двух версиях. При запуске без дополнительных параметров интеграционные проверки ScoreHud и AmyxAnvil пропускаются.

Серверные тесты используют настоящие мир, SQLite, предметы, обработку событий и транзакции крафта/наковальни. Подменяется транспорт игрока и его состояние, которое обычно задаёт сетевой вход. Тестовый атакующий подставляется вместо поиска сетевого игрока в реестре мира. Блоки меняются штатными методами мира; проверяются отмена, отсутствие изменений, многоблочная установка и несколько изменений одной позиции в одном тике. Временные наблюдатели изменений снимаются после обработки.

Для ScoreHud загружаются официальные классы API версии 8.0.0, commit `3f5b13b3daef0de3d2f5f81ad899dbbcc9eaf52f`. Чужой код в производственный PHAR и архив исходников AmyxStats не включается. Для наковальни применяется готовый AmyxAnvil 1.0.2 и настоящая его транзакция.

Ошибку записи SQLite моделирует триггер, который отклоняет одну из записей: проверяется полный откат транзакции и сохранение изменений в памяти для повторной записи. Это не моделирование всех возможных отказов диска. Отсутствующие данные до установки плагина тестами не восстанавливаются.

Графический клиент Bedrock, все промежуточные версии PM5, сторонние ядра и произвольные комбинации защитных/игровых плагинов отдельно не тестировались. API событий столика зачарования отсутствует в ранних PM5: соответствующий обработчик подключается только при наличии события в ядре.

```bash
/path/php -n tests/core.php
python3 tools/test-server.py \
  --php /path/php \
  --pmmp /path/PocketMine-MP.phar \
  --scorehud-source /path/ScoreHud \
  --anvil /path/AmyxAnvil.phar
```

Логи и JSON-результаты сохраняются в новом одноразовом каталоге `work/server-test-*`. Тестовые базы и миры не попадают в релиз.
