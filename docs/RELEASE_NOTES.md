# AmyxStats 1.0.0

Первый самостоятельный релиз статистики для PocketMine-MP 5.x.

- `/stat`, `/stats`, `/mystat`: русское меню, личные и общие значения, просмотр офлайн-игроков, топы и вывод в чат.
- 66 сохраняемых и 9 вычисляемых показателей: блоки, добыча, бои, смерти, предметы, перемещение, время игры и рекорды.
- 531 готовое имя плейсхолдера, включая личные и общие варианты, форматирование и ранги. Дополнительно — показатели по типам блоков, предметов и мобов.
- Необязательная интеграция со ScoreHud и API для других плагинов. При установленном AmyxAnvil учитываются его ремонт и переименование.
- SQLite, UUID, атомарное сохранение, общие значения в реальном времени, проверка отменённых и неподтверждённых действий.

Проверено 98 сценариев на PMMP 5.0.0 и 5.44.3, включая полные перезапуски серверов, настоящий крафт, AmyxAnvil и официальный API ScoreHud. Полный рендер в графическом Bedrock-клиенте не проверялся.

Установка: поместите `AmyxStats.phar` в `plugins/` либо распакуйте `AmyxStats-install.zip` в папку остановленного сервера. Сам плагин и меню не требуют зависимостей. Для вывода на доске нужен отдельно установленный ScoreHud. Исходники — `AmyxStats-source.zip`; полный каталог плейсхолдеров находится в `docs/PLACEHOLDERS.md`.
