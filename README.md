# AmyxStats

Статистика игроков и всего сервера для **PocketMine-MP 5.x**. Команды **`/stat`**, **`/stats`**, **`/mystat`** открывают русское меню. Есть просмотр офлайн-игроков, общий итог, топы и вывод в чат.

**66 сохраняемых + 9 вычисляемых показателей, 531 готовое имя плейсхолдера**, а также неограниченные варианты для отдельных типов блоков, предметов и мобов.

## Установка

1. Скачайте [AmyxStats-install.zip из последнего релиза](https://github.com/AlexVoids/AmyxStats/releases/latest) либо [AmyxStats.phar](https://github.com/AlexVoids/AmyxStats/releases/latest/download/AmyxStats.phar).
2. Поместите `AmyxStats.phar` в `plugins/` остановленного сервера и запустите сервер.
3. Введите `/stat`. Дополнительные плагины для самой статистики и меню не нужны.

Данные: `plugin_data/AmyxStats/statistics.sqlite`. Настройки: `config.yml`. Тексты ответов: `messages.yml`. Названия всех показателей: `labels.yml`. Поддерживаются цветовые коды `&` в сообщениях и префиксе. После изменения настроек полностью перезапустите сервер.

## Что собирается

- Строительство: сломанные и поставленные блоки, руды, брёвна, листва, зрелые культуры; отдельно каждый тип блока.
- Бои: убийства игроков и мобов, смерти и их причины, ближний бой и снаряды, нанесённый и полученный урон, PvP-урон, успешные удары, выпущенные снаряды и стрелы, попадания, восстановление здоровья.
- Рекорды: текущая и лучшая серии убийств, самая долгая сессия.
- Предметы: количество результатов крафта и выполненных рецептов, подобранные, выброшенные и употреблённые предметы, еда и зелья; отдельно каждый тип предмета.
- Зачарования на штатном столе, если ядро поддерживает `PlayerItemEnchantEvent`. Ремонт, переименование и объединение чар через AmyxAnvil учитываются автоматически при его установке.
- Перемещение: расстояние шагом, бегом, крадучись, вплавь, в полёте и на элитрах, прыжки, телепортации и переходы между мирами.
- Активность: входы, игровые дни UTC, время онлайн, сообщения, введённые команды, кровати, вёдра, открытые контейнеры и использования предметов.
- Вычисления: K/D, все убийства, все изменённые блоки, километры, минуты и часы игры, точность снарядов, блоки и убийства за час.

Полный список с точными ключами: [docs/PLACEHOLDERS.md](docs/PLACEHOLDERS.md).

События отменённых действий не увеличивают счётчики. Изменения блоков подтверждаются через штатные слушатели чанков, поэтому учитывается и блок, который успели поставить и убрать в одном тике. Многоблочная установка считает физические блоки: дверь может дать два блока. Крафт учитывает реальное количество результата, включая массовый крафт.

## Команды

| Команда | Действие |
| --- | --- |
| `/stat`, `/stats`, `/mystat` | Моя статистика |
| `/stat Ник` | Статистика известного игрока, в том числе офлайн |
| `/stat UUID` | Просмотр по UUID |
| `/stat global` | Общая статистика сервера |
| `/stat top kills` | Топ по убийствам игроков |
| `/stat top blocks_broken` | Топ по сломанным блокам |
| `/stat top playtime_seconds` | Топ по времени игры |
| `/stat top block_break:diamond_ore` | Топ по конкретному типу блока |
| `/stat chat` | Все свои показатели в чат |
| `/stat placeholders` | Примеры плейсхолдеров |
| `/stat help` | Справка |

Все три названия команды являются алиасами одной команды. Консоль может смотреть общие значения, игрока по нику или топ. Для ников, совпадающих с подкомандами, используйте UUID. Топы доступны по сохраняемым показателям; вычисляемые коэффициенты вроде K/D в топ не входят.

Разрешения `amyxstats.command`, `amyxstats.others`, `amyxstats.global`, `amyxstats.top`, `amyxstats.track` по умолчанию доступны всем. Последнее разрешение управляет сбором статистики. В настройках можно выключить формы, включить сбор игровых действий в творческом режиме и режиме наблюдателя, исключить миры и изменить период сохранения и обновления ScoreHud. Время онлайн и игровые дни считаются во всех мирах и режимах, включая AFK; обычные игровые действия в creative/spectator по умолчанию исключены.

## Плейсхолдеры и ScoreHud

ScoreHud необязателен. При установленном [ScoreHud](https://github.com/Ifera/ScoreHud) AmyxStats подключает его официальный событийный API. Используйте в строках ScoreHud:

```text
{amyxstats.my.blocks_broken}
{amyxstats.my.blocks_placed}
{amyxstats.my.kills}
{amyxstats.my.deaths}
{amyxstats.my.kdr}
{amyxstats.my.playtime_formatted}
{amyxstats.my.kills_rank}
{amyxstats.global.blocks_broken}
{amyxstats.global.kills}
{amyxstats.global.unique_players}
{amyxstats.my.block_break:diamond_ore}
```

Есть `_formatted` для разделения тысяч и `_compact` для сокращений K/M/B/T. Для каждого сохраняемого показателя есть личный `_rank`. Общие рекорды используют максимум; обычные общие счётчики — сумму. Общие коэффициенты вычисляются из общих исходных счётчиков, а не складываются из коэффициентов игроков.

Готовый пример строк: [docs/SCOREHUD.md](docs/SCOREHUD.md). Полный каталог: [docs/PLACEHOLDERS.md](docs/PLACEHOLDERS.md), машинный список: [docs/placeholders.json](docs/placeholders.json).

Для других плагинов предоставлен [API замены плейсхолдеров](docs/API.md), принимающий также `%amyxstats_my_kills%` и `{amyxstats_my_kills}`. Если другой плагин не вызывает этот API и не имеет адаптера, сам по себе текст в нём не заменится. В этой версии готовый адаптер поставляется для ScoreHud.

## Хранение и точность

UUID — идентификатор игрока, ник сохраняется как отображаемое имя. Регистр ника не влияет на поиск. История ведётся с момента установки; прошлые события не восстанавливаются. При изменении способа авторизации сервера UUID могут поменяться — такие игроки будут отдельными записями.

SQLite хранит офлайн-игроков, в памяти находятся активные профили и общие суммы. Автосохранение — раз в 10 секунд по умолчанию, выход и штатное выключение сохраняют данные. База использует WAL и транзакции. После принудительного завершения процесса могут пропасть ещё не сохранённые последние события. Для резервной копии остановите сервер и скопируйте папку данных целиком.

Время сессии измеряется монотонными часами и не включает время выключенного сервера. Дата первого входа, последнего присутствия и игровые дни используют UTC. `commands_used` считает принятый ввод команды, в том числе неизвестной; это не подтверждение успешного выполнения команды. `items_used` — принятые события использования предмета из ядра, а не любое касание экрана.

Убийство приписывается игроку, если последняя причина урона указывает на него или его снаряд. Отдельная логика плагинов боевого выхода, ассистов и отложенного PvP-добивания не добавляется. Мобы и игровые механики, которых нет в ядре, сами по себе не появляются: AmyxStats считает их события, если их создаёт ядро или другой плагин. Размещение/ломание от WorldEdit и других плагинов без соответствующего события игрока не считается его действием.

## Проверка и сборка

Проверено на официальных PocketMine-MP **5.0.0 / PHP 8.1.34** и **5.44.3 / PHP 8.4.16**. Подробности и границы проверки — [docs/TESTING.md](docs/TESTING.md). Графический Bedrock-клиент в этой среде не запускался.

```bash
/path/php -n tests/core.php
python3 tools/test-server.py --php /path/php --pmmp /path/PocketMine-MP.phar
/path/php -n -d phar.readonly=0 tools/build.php
python3 tools/package-release.py
```

Для дополнительных интеграционных проверок укажите `--scorehud-source /path/ScoreHud` и `--anvil /path/AmyxAnvil.phar`. Тесты запускают отдельные серверные процессы в `work/`; не ставьте тестовый PHAR на рабочий сервер. `tools/generate-catalog.php` обновляет стандартные названия и документацию плейсхолдеров.

Производственный PHAR содержит только код, `plugin.yml` и настройки. В установочном архиве нет тестовых серверов, временных файлов, чужих плагинов и зависимостей. Исходники со сборочными инструментами и тестами — в `AmyxStats-source.zip`. Лицензия: [MIT](LICENSE).
